[Assignment: Llm Prompter Prototype]
[Course: COMMLD-515]
[Concepts: personas, prototyping, design-thinking, ai-design, presentation]

ou will operationalize your team’s Agent Persona into a working LLM-based prototype (prompt + instructions + tool configuration) that delivers your Pitch value proposition, executes the Journey Map moments that matter, and supports the needs/constraints of your User Persona(s). This is not a generic chatbot. It is a purpose-built agent that can be tested, measured, and iterated. Inputs You Must Use (from prior assignments) You are required to directly incorporate the following artifacts into your prototype: Agent Persona (agent role, responsibilities, boundaries, decision style, tone, escalation rules) Working Backwards Pitch (problem, customer, promise, key differentiators, success criteria) Customer Journey Map (touchpoints, pain points, opportunities, emotions; identify “moments that matter”) User Persona(s) (goals, constraints, behaviors, context of use, accessibility considerations) What You Will Build A prototype LLM agent configuration using one of the following: ChatGPT (Custom GPT or structured prompt pack) Claude (project + system prompt + test set) Amazon Nova (prompt + policy + test set) Kiro (or any equivalent “agent builder” tool your team can access) Your prototype must demonstrate at least one end-to-end “happy path” from your journey map, plus failure handling for common edge cases.
