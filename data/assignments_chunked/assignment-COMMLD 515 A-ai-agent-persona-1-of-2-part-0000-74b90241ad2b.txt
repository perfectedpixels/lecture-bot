These principles are not philosophical—they are design constraints. 1. Agent behavior is a design artifact The behavior of an AI agent is as much a UX artifact as a persona, journey map, or information architecture. Agents must have defined roles, boundaries, tone, and escalation logic. “Prompting” is not interaction design;behavioral specification is. An agent that behaves inconsistently or opaquely is a design failure. 2. Assistance, not ownership AI agents may support human decision-making, but must not replace it. The agent should guide, frame, summarize, and surface options. The agent must not decidefor the user in high-impact contexts. Human-in-the-loop is a success criterion, not a feature request. 3. Context determines risk The same AI capability can be benign or harmful depending on where it appears in the user journey. Low-consequence contexts tolerate exploration and error. High-consequence contexts (health, mental well-being, safety, identity) require strict constraints. Agents must adapt behavior based on journey moment, not just user intent. 4.
