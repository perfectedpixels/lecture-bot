Agent Behavior Maker — summary What the tool does Agent Behavior Maker is a workflow tool for designing and stress-testing how an LLM-powered agent should behave for a specific product. You feed in structured inputs about the product, the end user, and the agent you want to build. The app uses AWS Bedrock (Claude) to: Extract structured insights from your documents (product, persona, agent framework). Generate multiple conversation scenarios that fit your domain. Simulate multi-turn chats between PersonaUser (your user) and AgentLLM (your agent). Let you tune behavior with controls (tone, formality, verbosity, empathy, proactivity, creativity, technical depth) and regenerate the simulated conversation so you can see the effect. Optionally continue the simulation by typing your own messages (user interrupt). Export downloadable artifacts that encode what you learned. It does not replace production deployment; it helps you iterate on persona and steering before you wire them into your real system. What the output is Output Description On screen Scenarios (clickable cards) and simulated conversations (alternating user/agent messages) that reflect your documents and current control settings.
